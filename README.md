 OTP Verification

A simple and responsive **OTP Verification Component** using **HTML, CSS, and JavaScript**.  
It lets users enter a One-Time Password and validates it with success or error messages.

# Features
- Auto-focus OTP input fields  
- Instant validation (correct/incorrect OTP)  
- Clean and responsive UI
